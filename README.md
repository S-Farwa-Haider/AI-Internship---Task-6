# Task 6: House Price Prediction

## Objective

The objective of this task is to predict house prices using property-related features such as area, bedrooms, and bathrooms.

---

## Dataset Used

- Housing Dataset

The dataset contains:
- Area
- Bedrooms
- Bathrooms
- Stories
- Parking
- Price
- Other housing attributes

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

---

## Machine Learning Model Used

- Linear Regression

---

## Tasks Performed

- Loaded and explored housing dataset
- Performed data visualization
- Created histograms and heatmaps
- Selected important housing features
- Split dataset into training and testing sets
- Trained Linear Regression model
- Predicted house prices
- Compared actual vs predicted prices

---

## Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

---

## Visualizations Included

- Histograms
- Correlation Heatmap
- Actual vs Predicted Price Graph

---

## Skills Learned

- Regression modeling
- Feature selection
- Data visualization
- Model evaluation
- Real estate data analysis

---

## Conclusion

This task demonstrated how machine learning regression models can be used for house price prediction based on property-related features.
